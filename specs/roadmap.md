# Roadmap

基于 TODO.md:Now = 反馈表单;Next = 客户评价、About 页面。每个阶段都很小,可独立完成和验证。

## Phase 0 - 基础
1. 初始化 Next.js + TypeScript 项目,能运行首页。
2. 加入全局布局(页头/页脚)和基础样式。
3. 接入 SQLite 和数据访问层,建一张测试表。

## Phase 1 - 反馈表单(Now)
1. 创建 `/feedback` 页面,仅显示表单(姓名、消息)。
2. 增加客户端校验和提交状态。
3. 创建 API 路由,把反馈存入 SQLite。
4. 提交成功后显示感谢信息。
5. 为校验和 API 加测试。

## Phase 2 - 客户评价(Next)
1. 建 reviews 表和种子数据。
2. 创建 `/reviews` 页面,列出评价。
3. 加入星级显示。
4. 加入提交评价的表单。

## Phase 3 - About 页面(Next)
1. 创建 `/about` 页面,含诊所介绍和地址。
2. 嵌入地图。
3. 在导航中加入链接并检查响应式。

## Phase 4 - 产品功能(来自 Susan,待细化)
1. 病症列表与详情页。
2. 疗法列表与详情页。
3. 预约:选择疗法与时间。
4. 预约确认与查看。

## Phase 5 - 员工仪表盘(待细化)
1. 简单仪表盘首页:反馈、评价、预约数量。
2. 员工认证。
3. 预约和反馈管理视图。
