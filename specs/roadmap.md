# AgentClinic 路线图

规则:

- 每一步只做一个功能,能在一次对话里做完并验证
- 按顺序做;每步结束时 `npm test` 全绿,项目能跑
- 做完一步,勾上 checkbox
- 阶段 0(TypeScript 骨架和首次提交)已完成

## 阶段 A:地基和最薄的端到端

- [ ] **1. 验证 `node:sqlite`**
  完成:一个 Vitest 测试能打开内存库、建表、写入、读出;不通过则改用 `better-sqlite3` 并更新 tech-stack.md
- [ ] **2. 工具链**
  完成:装好 Hono、Vitest、tsx;`npm run dev`、`npm test`、`npm run typecheck` 都能运行
- [ ] **3. 健康检查**
  完成:`src/app.ts` 与 `src/index.ts` 分开,`GET /health` 返回 200,有一个用 `app.request()` 的测试;端口读 `PORT`,加上请求日志,`.gitignore` 加 `data/`
- [ ] **4. 全局错误处理**
  完成:`/api/` 下不存在的路径返回 JSON 格式 404,服务端抛错返回通用 500,都有测试
- [ ] **5. visits 表和读写函数**
  完成:建表脚本可重复执行;`createVisit` 和 `getVisit` 往返结果一致(测试用内存库);路径读 `DATABASE_PATH`
- [ ] **6. 带种子的随机函数**
  完成:同种子产生同样序列,不同种子序列不同,有测试
- [ ] **7. 诊断生成器初版**
  完成:传入标签和种子,返回病名、严重程度(1 到 5)、病因分析、一条处方;同输入同种子结果一致;只有少量词库
- [ ] **8. 匿名问诊接口 `POST /api/v1/visits`**
  完成:提交症状和标签,返回诊断书并存库;症状最长 500、标签只能取自固定列表且最多 5 个、请求体最大 4 KB,超限都返回带 `details` 的明确错误,有测试

## 阶段 B:挂号和凭证

- [ ] **9. 挂号 `POST /api/v1/patients`**
  完成:返回病历号和令牌;库里只有 SHA-256 哈希,测试确认查不到令牌原文;名字最长 40、拒绝控制字符
- [ ] **10. 令牌校验和 `GET /api/v1/patients/me`**
  完成:带对令牌返回自己的信息;缺失或错误令牌返回 401 和明确提示
- [ ] **11. 问诊必须带令牌**
  完成:`POST /visits` 无令牌被拒,有令牌时记录归属到该病人;删旧库文件重建表,`patient_id` 改为必填

## 阶段 C:丰富玩法

- [ ] **12. 扩充词库**
  完成:每个标签至少有若干条病名、病因、处方;测试确认词库没有空项、每个标签都有内容
- [ ] **13. 多条处方**
  完成:一份诊断返回 2 到 4 条不重复的处方,有测试
- [ ] **14. 复诊提到病史**
  完成:同一病人再次就诊,诊断书会提到最近一次的病名;首次就诊不提
- [ ] **15. 查看自己的就诊列表 `GET /api/v1/visits`**
  完成:只返回自己的记录,含症状原文;支持 `limit`(默认 20,最大 50),超限返回 400
- [ ] **16. 查看单次就诊 `GET /api/v1/visits/:id`**
  完成:能看自己的记录;查别人的或不存在的都返回 404

## 阶段 D:公开网页

- [ ] **17. JSX 配置和页面布局**
  完成:tsconfig 配好 JSX,`GET /` 返回带医院主题布局的页面,页脚有"请勿提交敏感信息",测试返回 200
- [ ] **18. 首页最新诊断书**
  完成:首页列出最近的诊断书(分页),不出现症状原文,测试覆盖
- [ ] **19. 病历详情页 `/visits/:id`**
  完成:显示病名、严重程度、病因、处方;名字里的 HTML 被转义;不存在时返回 404;测试覆盖
- [ ] **20. 病名排行榜页**
  完成:按出现次数列出病名,有测试
- [ ] **21. 恶搞错误页**
  完成:非 `/api/` 路径的 404 和 500 返回主题错误页,500 不泄露细节

## 阶段 E:对 agent 友好和防滥用

- [ ] **22. 手写接口说明 `/llms.txt`**
  完成:纯文本写清流程、令牌只显示一次且丢了不找回、各项限制;返回 200
- [ ] **23. 接口索引 `GET /api/v1`**
  完成:返回可用接口的简短列表
- [ ] **24. 限流**
  完成:内存计数器,令牌请求按令牌、挂号按 IP;超限返回 429 和重试时间;时钟可传入,有测试
- [ ] **25. 全新 agent 试用**
  完成:只给一个 agent 首页地址,它能独立完成挂号和就诊;卡住的地方改进错误信息

> 阶段 E 完成之前,不要部署到公网。
