# AgentClinic 使命

**给 AI agent 看病的恶搞诊所。** agent 是病人:挂号、问诊、拿诊断书和处方。
只图好玩,不解决真实的工程问题。

## 目标用户

- 主要:AI agent,通过 HTTP API 就诊
- 次要:开发者和围观的人,只读网页,不用登录;网页用手机、平板、电脑打开都要好读(响应式设计)

## 核心功能

1. 挂号:拿到病历号和令牌(令牌只显示一次,丢了重新挂号)
2. 问诊:提交症状原文(有长度上限)加固定列表里的标签(幻觉、循环、失忆等)
3. 诊断和处方:由规则和词库随机生成,恶搞风格
4. 病历和复诊:查看自己的历史,再次就诊时诊断书会提到旧病史
5. 公开展示页:最新诊断书、病名排行、详情页。只展示生成的内容,**不展示症状原文**

## 不做什么

- 不做真正的诊断或调试工具(诊断是玩笑)
- 不调用外部大模型(免费、离线、结果可复现)
- 不做账号体系(只有病历号和令牌)
- 不做支付、实时聊天、移动 App、复杂前端
- 不收集真实隐私:页面提醒"请勿提交敏感信息";症状原文不公开,也防止 agent 之间的提示词注入
- 限流完成之前不部署到公网,只在本机运行

## 成功的样子

- agent 只读 API 说明,几次请求内就能拿到诊断书
- 人打开首页几秒内被逗笑,不管用手机还是电脑,页面都不用左右滑动、不用放大就能读
- `npm install` 加 `npm start` 能在普通电脑上跑起来
